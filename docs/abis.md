# `alkanesjs/abis` — shipped ABI documents

```ts
import { OylAMMAbi, OylAMMPoolAbi, FrBTCAbi, TokenAbi } from "alkanesjs/abis";
```

alkabi-generated documents for widely-deployed contracts, shipped so common
integrations don't start with an extraction step:

| Export | Contract |
| --- | --- |
| `OylAMMAbi` | the Oyl AMM factory (the router: find pools, swap through paths) |
| `OylAMMPoolAbi` | one Oyl AMM pool (reserves, fee, direct swap) |
| `FrBTCAbi` | frBTC, the synthetic-BTC alkane (wrap, unwrap, premium, signer) |
| `TokenAbi` | the plain mintable-token interface most tokens speak (name, symbol, supply, mint) |

**Documents, not bindings.** These carry no alkane ids — which deployment you
talk to is always yours to say, which is what keeps the no-contracts rule
intact:

```ts
import { AlkaneId, Contract } from "alkanesjs";
import { FrBTCAbi, OylAMMPoolAbi } from "alkanesjs/abis";

const frbtc = new Contract(FrBTCAbi, AlkaneId.fromString("32:0"), provider);
const pool = new Contract(OylAMMPoolAbi, POOL_ID, provider);

const premium = await frbtc.getPremium().unwrap();          // bigint
const [reserves, fee] = await pool
  .bundle()
  .getReserves().unwrap()
  .getTotalFee().unwrap();
```

`TokenAbi` is the interface answer to "I just want to read any token" —
name, symbol, supply, cap, mint — and most alkanes tokens (controlled-mint
clones included) answer its view opcodes:

```ts
const token = new Contract(TokenAbi, someTokenId, provider);
const [name, symbol, supply] = await token
  .bundle()
  .getName().unwrap()
  .getSymbol().unwrap()
  .getTotalSupply().unwrap();
```

Every file in this entry is generated output (`// Generated by alkabi — do
not edit.`): regenerate from the contract wasm to update one, or correct at
the consuming end with `withOverrides` ([abi.md](./abi.md)) — never by
editing the file.

Pairs naturally with the utils entries: `alkanesjs/utils/amm` prices trades
against the reserves `OylAMMPoolAbi` reads; `alkanesjs/utils/frbtc` computes
the premium and signer that make `FrBTCAbi`'s `wrap` usable
([utils-frbtc.md](./utils-frbtc.md) shows the full wrap).
